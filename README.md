# Bateco Revenue — Enterprise BI

Dashboard doanh thu Bateco theo Figma: chỉ tiêu, kỳ vọng, gói thầu và hiệu suất giám đốc / chi nhánh.

## Screens

| Route | Mô tả |
|------|--------|
| `/` | Tổng quan doanh thu |
| `/so-sanh-nam` | So sánh các năm |
| `/so-sanh-nhan-su` | So sánh nhân sự |
| `/phu-trach/[id]` | Chi tiết phụ trách |
| `/thuat-ngu` | Thuật ngữ |
| `/sap-ra-mat` | Stub cho mục chưa có |

## Tech

Next.js 16 · shadcn/ui · Tailwind CSS v4 · Recharts · next-themes · Lucide

## Start

```bash
pnpm install
pnpm dev
```

Mở [http://localhost:3000](http://localhost:3000).
